Calculation Formula

Manufacturing LT = (Base LT + Drawing Breakdown LT + Difficulty Buffer + Special Treatment Buffer) × Quantity Factor

Applied Difficulty Level = higher of Customer Level and Branch Count Level

ETD = Manufacturing Start Date + Total Manufacturing LT

Version 2.6. Calendar days are used for ETD calculation. CCT above 1,000 and Level 5 require advance discussion.

Integration (BOM Analyzer / Drawing Recognition)

Upstream tools can pre-fill the calculator. Values are filled in only; a person reviews them and presses Calculate. Wire count is used as the CCT count.

1. Input JSON — use Load from BOM / Drawing JSON on the Calculator tab. Download a sample file.

{
  "schema": "manufacturing-lt/input@1",
  "customer": "KOBELCO",
  "wireCount": 180,
  "branchCount": 25,
  "qty": 20,
  "startDate": "2026-10-09",
  "specials": ["Marker", "Braiding"],
  "source": {
    "tool": "BOM Analyzer", "drawingNo": "WH-12345", "revision": "B",
    "detected": ["wireCount", "branchCount", "specials"],
    "bom": [{ "partNo": "CN-001", "description": "Connector 12P", "qty": 2, "leadTimeDays": 21 }]
  }
}

2. Link — e.g. index.html?wireCount=180&branchCount=25&customer=KOBELCO&qty=20&specials=Marker,Braiding&drawingNo=WH-12345

3. Shared formula — lt-core.js exposes LTCore.parseInput(payload, master) and LTCore.calcLeadTime(inputs, master) for use in another app.

BOM part lead times are shown but not added to the LT yet; the rule for combining material and manufacturing LT is still to be decided.
